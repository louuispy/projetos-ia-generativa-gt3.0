# Módulo 3 – Automações e Agentes de IA com N8N

Projetos desenvolvidos e lecionados durante o curso de IA Generativa do **Geração Tech 3.0**.

O módulo cobre desde automações simples até agentes de IA com MCP, pipelines de dados e RAG aplicado.

## Projetos

| # | Projeto | Descrição |
|---|---------|-----------|
| 01 | Automação de RH – GT Systems | Fluxo automatizado para triagem e gestão de processos de RH |
| 02 | Introdução a MCP | Primeiros passos com Model Context Protocol no N8N |
| 03 | Agente de IA com MCP – GT Systems | Agente integrado via MCP para automação de processos internos |
| 04 | Automação de Estoque – GT Farmácia | Fluxo de atualização autônoma de estoque via linguagem natural |
| 05 | Agente de IA de Estoque – GT Farmácia | Agente com alertas automáticos por e-mail para estoque crítico |
| 06 | DataLake de Ideias de Posts – GT Studios | Pipeline de coleta e armazenamento de ideias de conteúdo |
| 07 | DataLake com Telegram – GT Studios | Versão integrada ao Telegram para captura de ideias em tempo real |
| 08 | ETL com dados do IMDB | Pipeline de extração, transformação e carga de dados do IMDB |
| 08 | RAG com dados do IMDB | Sistema de RAG aplicado sobre dados do IMDB com respostas contextuais |

## Stack
N8N · Agentes de IA · MCP · LangChain · Python · RAG · APIs
